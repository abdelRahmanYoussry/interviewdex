# InterviewDex

Real interview questions for Flutter developers. Built with Flutter.

[Live demo](https://abdelRahmanYoussry.github.io/interviewdex/)

InterviewDex is an interview preparation app for Flutter developers. I built
it to make it easier to practice realistic questions and understand the
reasoning behind answers.

## Features in v0.1

- Quick quiz with right/wrong feedback, a why, and a tip after every answer.
- Interview practice with self-rating and spaced repetition.
- 10-question mock interview with a weak-topics summary.
- English and Arabic UI with RTL support.
- Light and dark themes.
- Progress saved on the device only.

## How to run

Use Flutter 3.29.3:

```shell
flutter pub get
flutter run -d chrome
flutter test
```

## How to contribute

Content lives in `assets/tracks`. See the [content guide](assets/tracks/README.md)
for the schema and review rules: accurate answers, plausible wrong options,
plain English, and a source for every item.
